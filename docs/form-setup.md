# お問い合わせフォームの設定手順

サイトのお問い合わせフォームは、入力された内容を **Googleフォーム** に送り、**Google Apps Script** でメールを送ります。
この手順書では、次の4つの作業を順番に説明します。所要時間はおよそ30〜45分です。

1. Googleフォームを作る
2. 送信先URLと項目IDを調べて、サイトに反映する
3. Apps Script を設定する（自動返信メール・通知メール）
4. テスト送信で確認する

> **用意するもの**
> - bullのお問い合わせを受け取る Google アカウント（Gmail など）
> - 通知メールを受け取るメールアドレス
> - パソコン（スマートフォンでは設定できない画面があります）

> **注意**
> 画面のボタン名や配置は、Google の更新で少し変わることがあります。見当たらないときは、似た名前のボタンを探してください。

---

## 1. Googleフォームを作る

### 1-1. 新しいフォームを作る

1. ブラウザで [https://forms.google.com/](https://forms.google.com/) を開き、bull用の Google アカウントでログインします。
2. 「新しいフォームを作成」の **「空白のフォーム」**（大きな「＋」のマーク）をクリックします。
3. 左上の「無題のフォーム」をクリックし、タイトルを **`株式会社bull お問い合わせ`** に変えます。
   （このタイトルは、サイトの利用者には表示されません）

### 1-2. 質問を6つ作る

最初から「無題の質問」が1つあります。これを1つ目の質問として使い、残りは画面右側の **「⊕（質問を追加）」** ボタンで追加します。

質問ごとに、次の3つを設定します。

- **質問のタイトル**：下の表の「タイトル」を **1文字も変えずに** 入力します（コピー＆貼り付けがおすすめです）
- **質問の種類**：タイトルの右にある選択欄で選びます
- **「必須」のスイッチ**：質問の右下にあります。**すべてオフ** にしてください

| 順番 | タイトル（このとおりに入力） | 質問の種類 |
|---|---|---|
| 1 | `会社名` | 記述式 |
| 2 | `お名前` | 記述式 |
| 3 | `メールアドレス` | 記述式 |
| 4 | `電話番号` | 記述式 |
| 5 | `お問い合わせカテゴリ` | ラジオボタン |
| 6 | `お問い合わせ内容` | 段落 |

> **なぜ「必須」をオフにするの？**
> 入力チェックはサイト側で行っています。Googleフォーム側で必須にすると、電話番号のような任意の項目を空欄で送ったときに、回答が記録されなくなることがあります。

#### 5番「お問い合わせカテゴリ」の選択肢

種類を「ラジオボタン」にすると「オプション1」が表示されます。クリックして、次の5つを順番に入力します（1つ入力したら、下の「選択肢を追加」で次を追加します）。

```
営業支援について
販路拡大について
海外ビジネスについて
ビジネスマッチングについて
その他
```

> **重要**
> 選択肢の文字は、サイト側（`src/data/contactForm.ts` の `categories`）と **完全に同じ** にしてください。1文字でも違うと、カテゴリが記録されません。
> 「『その他』を追加」という機能は使わないでください。上のとおり、普通の選択肢として「その他」を入力します。

### 1-3. フォームの設定を変える

1. 画面上部の **「設定」** タブをクリックします。
2. **「回答」** の項目をクリックして開き、次のように設定します。

| 設定項目 | 設定する値 |
|---|---|
| メールアドレスを収集する | **収集しない** |
| 回答のコピーを回答者に送信 | オフ（表示されない場合はそのままでOK） |
| 回答を1回に制限する | **オフ** |

3. Google Workspace（会社用の Google アカウント）を使っている場合は、**「〇〇内のユーザーと信頼できる組織のユーザーに限定する」** のような項目も **オフ** にします。

> **ここが一番つまずきやすいポイントです**
> 「メールアドレスを収集する」や「回答を1回に制限する」がオンだと、回答者に Google へのログインが求められます。そうなるとサイトからの送信が **記録されません**。

### 1-4. フォームを公開する

画面右上に **「公開」** ボタンがある場合は、クリックしてフォームを公開します（公開しないと回答を受け付けません）。
「回答を受け付けています」のスイッチが表示される場合は、オンになっていることを確認します。

## 2. 送信先URLと項目IDを調べて、サイトに反映する

サイトからGoogleフォームに送るには、次の2つの情報が必要です。

- **送信先URL**：`https://docs.google.com/forms/d/e/（長い英数字）/formResponse`
- **項目ID**：質問ごとに付いている `entry.（数字）` という番号（6つ）

どちらも「事前入力したURL」という機能を使うと、まとめて調べられます。

### 2-1. 事前入力したURLを取得する

1. フォームの編集画面の右上にある **「︙」（その他）** をクリックします。
2. **「事前入力したURLを取得」** をクリックします。新しいタブでフォームの入力画面が開きます。
3. 項目を見分けやすくするため、各質問に **次のとおり入力** します。

| 質問 | 入力する内容 |
|---|---|
| 会社名 | `AAA` |
| お名前 | `BBB` |
| メールアドレス | `CCC` |
| 電話番号 | `DDD` |
| お問い合わせカテゴリ | 「その他」を選ぶ |
| お問い合わせ内容 | `FFF` |

4. 画面下の **「リンクを取得」** をクリックし、表示された **「リンクをコピー」** をクリックします。
5. メモ帳などに貼り付けます。次のような長いURLになっています。

```
https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxxxxxx/viewform?usp=pp_url&entry.111111111=AAA&entry.222222222=BBB&entry.333333333=CCC&entry.444444444=DDD&entry.555555555=%E3%81%9D%E3%81%AE%E4%BB%96&entry.666666666=FFF
```

### 2-2. URLから必要な部分を読み取る

**送信先URL**
URLの先頭から `?` の手前までをコピーし、最後の `viewform` を `formResponse` に書き換えます。

```
https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxxxxxx/viewform   ← コピーした部分
https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxxxxxx/formResponse   ← 書き換えたもの（これを使う）
```

**項目ID**
`entry.数字=` の部分が、それぞれの質問のIDです。「=」の後ろの文字で、どの質問か見分けます。

| URLの中の部分 | どの質問か | 使う値 |
|---|---|---|
| `entry.111111111=AAA` | 会社名 | `entry.111111111` |
| `entry.222222222=BBB` | お名前 | `entry.222222222` |
| `entry.333333333=CCC` | メールアドレス | `entry.333333333` |
| `entry.444444444=DDD` | 電話番号 | `entry.444444444` |
| `entry.555555555=%E3%81...` | お問い合わせカテゴリ（「その他」が記号に変換されています） | `entry.555555555` |
| `entry.666666666=FFF` | お問い合わせ内容 | `entry.666666666` |

### 2-3. サイトに反映する

1. プロジェクトの **`src/data/contactForm.ts`** を開きます。
2. ファイルの上の方にある `googleForm` の部分を、調べた値に書き換えます。`'` （シングルクォート）は消さないでください。

```ts
export const googleForm = {
  actionUrl: 'https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxxxxxx/formResponse',
  entries: {
    company: 'entry.111111111',  // 会社名
    name: 'entry.222222222',     // お名前
    email: 'entry.333333333',    // メールアドレス
    tel: 'entry.444444444',      // 電話番号
    category: 'entry.555555555', // お問い合わせカテゴリ
    message: 'entry.666666666',  // お問い合わせ内容
  },
};
```

3. 保存します。
4. `npm run dev` でプレビューし、http://localhost:4321/contact/ を開きます。
   フォームの上にあった赤い枠の **「【制作中の表示】Googleフォームの送信先がまだ設定されていないため…」が消えていれば成功** です。
   消えない場合は、URLが `formResponse` で終わっているか、IDが `entry.数字` の形になっているかを確認してください。

## 3. Apps Script を設定する（自動返信メール・通知メール）

### 3-1. スクリプトを貼り付ける

1. Googleフォームの編集画面に戻り、右上の **「︙」（その他）** → **「スクリプト エディタ」**（または「Apps Script」）をクリックします。
   新しいタブで Apps Script の画面が開きます。
2. 左上の「無題のプロジェクト」をクリックし、名前を **`bull お問い合わせメール`** に変えて「名前を変更」を押します。
3. 中央のエディタに最初から書かれている `function myFunction() { }` を **すべて削除** します。
   （エディタ内をクリックし、`Command + A`（Windows は `Ctrl + A`）で全選択してから `Delete`）
4. プロジェクトの **`docs/google-apps-script.gs`** をテキストエディタで開き、中身を **すべてコピー** して、Apps Script のエディタに貼り付けます。
5. 貼り付けたコードの上の方にある **「設定（ここを書き換えてください）」** の部分を書き換えます。

| 設定名 | 書き換える内容 | 例 |
|---|---|---|
| `NOTIFY_TO` | お問い合わせの通知を受け取るアドレス | `'info@example.com'` |
| `FROM_NAME` | メールの差出人名（変更不要） | `'株式会社bull'` |
| `REPLY_TO` | 自動返信メールに返信されたときの宛先（空なら、このGoogleアカウント宛て） | `'info@example.com'` |
| `REPLY_ESTIMATE` | 返信までの目安 | `'3営業日以内'` |
| `AUTO_REPLY_SUBJECT` / `AUTO_REPLY_BODY` | 自動返信メールの件名・本文（必要なら） | — |
| `SIGNATURE` | 署名。【要入力】の部分（郵便番号、URL）を埋める | — |
| `NOTIFY_SUBJECT` | 通知メールの件名（必要なら） | — |

> `'`（シングルクォート）や `` ` ``（バッククォート）で囲まれた中身だけを書き換えてください。記号を消すとエラーになります。

6. 上部の **💾（プロジェクトを保存）** アイコンをクリックするか、`Command + S`（Windows は `Ctrl + S`）で保存します。

### 3-2. 権限を承認する（テストメールの送信）

最初に一度、テスト用の関数を実行して、メール送信の権限を承認します。

1. 画面上部の、関数名が表示されている選択欄（「onFormSubmit」などと表示）をクリックし、**`testSendMails`** を選びます。
2. その左の **「▷ 実行」** をクリックします。
3. 「承認が必要です」と表示されたら **「権限を確認」** をクリックします。
4. bull用の Google アカウントを選びます。
5. **「このアプリは Google で確認されていません」** と表示されたら、次の順に進みます（自分で作ったスクリプトなので問題ありません）。
   1. 左下の **「詳細」**（または「詳細を表示」）をクリック
   2. 一番下の **「bull お問い合わせメール（安全ではないページ）に移動」** をクリック
6. 権限の一覧が表示されたら、**「すべて選択」** にチェックを入れて（表示される場合）、**「許可」**（または「続行」）をクリックします。
7. 画面下の「実行ログ」に **「テストメールを送信しました」** と表示されれば成功です。
   `NOTIFY_TO` のアドレスに、**通知メールと自動返信メールの2通** が届いていることを確認します。

### 3-3. トリガーを設定する（フォーム送信時に自動で動かす）

1. Apps Script の画面の左端にある **⏰（時計のアイコン）「トリガー」** をクリックします。
2. 右下の **「＋ トリガーを追加」** をクリックします。
3. 次のように設定します。

| 項目 | 選ぶもの |
|---|---|
| 実行する関数を選択 | **onFormSubmit** |
| 実行するデプロイを選択 | **Head** |
| イベントのソースを選択 | **フォームから** |
| イベントの種類を選択 | **フォーム送信時** |
| エラー通知設定 | 毎日通知を受け取る（そのままでOK） |

4. **「保存」** をクリックします。権限の確認が出た場合は、3-2 の手順5〜6と同じように許可します。
5. トリガーの一覧に「onFormSubmit／フォームから／フォーム送信時」が1行表示されていれば完了です。

> **トリガーは1つだけにしてください。** 同じトリガーを2つ作ると、メールが2通ずつ届きます。

## 4. テスト送信で確認する

### 4-1. サイトから送信する

1. `npm run dev` でプレビューを起動し、http://localhost:4321/contact/ を開きます。
2. フォームに入力します。**メールアドレスには、自分で受信を確認できるアドレス** を入れてください。
3. プライバシーポリシーへの同意にチェックを入れ、「入力内容を送信する」を押します。
   - ページを開いてから **3秒以内** に送信すると、スパム対策のため実際には送信されません。普通に入力すれば問題ありません。
4. **送信完了ページ（「お問い合わせありがとうございます。」）が表示される** ことを確認します。

### 4-2. 確認する3つのポイント

| 確認すること | 確認する場所 | うまくいっている状態 |
|---|---|---|
| ① 回答が記録されたか | Googleフォームの編集画面 → 上部の **「回答」** タブ | 回答数が1増え、入力した内容が表示される |
| ② 自動返信メール | フォームに入力したメールアドレスの受信箱 | 件名「【株式会社bull】お問い合わせを受け付けました」のメールが届き、入力内容の控えが入っている |
| ③ 通知メール | `NOTIFY_TO` に設定したアドレスの受信箱 | 件名「【お問い合わせ】（カテゴリ）／（会社名）（お名前） 様」のメールが届き、入力内容がすべて入っている |

メールが届くまで、1〜2分かかることがあります。**迷惑メールフォルダ** も確認してください。

> 「回答」タブの **「スプレッドシートにリンク」**（緑のアイコン）を押すと、回答がスプレッドシートにも自動で記録されるようになります。一覧で管理したいときに便利です。

### 4-3. うまくいかないとき

| 症状 | 考えられる原因と対処 |
|---|---|
| 送信完了ページは出るが、「回答」タブに記録されない | ・1-3 の設定（メールアドレスを収集しない／回答を1回に制限しない）を確認<br>・1-4 でフォームを公開したか確認<br>・`src/data/contactForm.ts` の送信先URL・項目IDが正しいか確認（2-1 からやり直す）<br>・質問を「必須」にしていないか確認 |
| カテゴリだけ記録されない | 選択肢の文字がサイト側と完全に同じか確認（1-2） |
| 回答は記録されるが、メールが届かない | ・Apps Script の左端 **「実行数」**（≡ のようなアイコン）を開き、赤い「失敗」がないか確認。クリックするとエラー内容が見られる<br>・3-3 のトリガーが設定されているか確認<br>・`NOTIFY_TO` が正しいメールアドレスか確認 |
| メールの内容が「（未入力）」ばかりになる | Googleフォームの質問タイトルが、スクリプトの `QUESTIONS` と同じか確認（全角・半角、空白に注意） |
| メールが2通ずつ届く | トリガーが2つ登録されている。1つ削除する |

---

## 運用上の注意

- **質問のタイトルや選択肢を変えるとき** は、Googleフォーム・`src/data/contactForm.ts`・Apps Script の `QUESTIONS` の3か所をそろえてください。質問を作り直した場合は項目IDも変わるため、2章をやり直します。
- **送信できるメールの数には上限があります**（無料の Gmail アカウントでは1日あたり約100通）。通常のお問い合わせ件数であれば問題ありません。
- **スパム対策について**：サイトのフォームには、利用者の手間が増えない対策（人には見えない入力欄、送信の速さのチェック、二重送信の防止）を入れています。ただし、Googleフォームに直接データを送ってくる迷惑行為は、サイト側では防げません。迷惑な送信が増えた場合はご相談ください（reCAPTCHA などの追加対策を検討します）。
- 返信までの目安は、サイト側（`src/data/contactForm.ts` の `replyEstimate`）と Apps Script（`REPLY_ESTIMATE`）の **2か所** に書かれています。変えるときは両方を変更してください。
